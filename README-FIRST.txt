Reveal Sheet v0.1.0 - development build

Open reveal-sheet.html or dist/index.html in a JavaScript-capable browser.
This version supports local image input and preview only.
Cover editing, studying, saving and reopening sheets are NOT implemented yet.
All work is in memory and is lost when the page closes.

Source build on Windows:
  powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/check-repository.ps1

For development tests and limits, read README.md / README.ja.md.
Do not merge the development Draft PR automatically.
