# Reveal Sheet / めくる暗記シート

[English](README.md)

答えが書かれた図・写真・ノートを、めくって確認する教材にするツールです。**現在のv0.1.0開発版は画像の読み込み・確認までです。覆いの編集、学習、教材ファイルの保存・再読込はまだ利用できません。** 正式版v1.0.0の完成を意味しません。

## 現在できること

JPEG・静止PNG・静止WebPを複数選択し、向きを固定したPNGへ縮小せず変換して、選択順に表示します。ファイル選択に加え、PCのドロップと画像ファイルの貼り付けに対応します。失敗した画像は理由付きで別表示し、中止しても処理済みのページは残します。「新しい教材」は確認後に切り替え、古い読み込み結果を持ち込みません。

ページ追加には最大100操作のUndo／Redoがあります。日英切替、ライトUI、320 CSS pxからの画面構成を実装しています。言語切替で教材名やページ名などのユーザーデータは変更しません。

## 使い方

生成された`reveal-sheet.html`または`dist/index.html`をブラウザで開き、「画像を追加」から画像を選びます。ページを選ぶと、向き・寸法・PNG化後の容量を確認できます。**この開発版には保存機能がありません。画面を閉じると画像と作業内容は失われます。** 学習・保存・教材を開くボタンは、未実装であることが分かるよう無効になっています。

表示するのは編集・入力確認用の画像です。この段階では画像を覆わず、学習用画面はまだ提供しません。

## 対応形式と上限

| 対象 | 上限 |
|---|---|
| 入力画像1枚 | 20 MiB |
| 画像寸法 | 各辺8192 px、総画素16,000,000以下 |
| 向き固定後のPNG | 1枚32 MiB |
| 教材内の画像 | 合計64 MiB |
| ページ数 | 30 |

これらは入力を拒否する安全上限であり、全端末での処理能力の実測値ではありません。上限を満たすために画像を自動縮小しません。PNG化により容量が増えることがあります。

GIF、APNG、アニメーションWebP、SVG、HEIC／HEIF、AVIF、PDFは非対応です。URLやHTMLを貼り付けても外部の画像を取得しません。

## プライバシー

画像はブラウザ内で処理します。元ファイル名は失敗した画像を示す一時表示にだけ使い、教材名・ページ名・画像メタデータには引き継ぎません。元画像のバイト列やEXIFを教材へ意図してコピーしませんが、画素に写った氏名や場所は消えません。この版では画像や学習記録を端末の保存領域にも永続化しません。

**覆いは学習用です。元の答えや画像は教材ファイルに含まれます。個人情報や機密情報を消す機能ではありません。** この注意は後続の覆い・出力機能にも適用する契約であり、その機能自体はv0.1.0では未実装です。教材として配布するときは、配布する権限のある資料を使用してください。

CDN、外部フォント、計測・広告、外部APIを使用しません。`connect-src 'none'`と外部画像・フレーム・Workerを許可しないCSPを設定し、静的検査とブラウザの通信観測を分けて記録します。[検証結果](docs/QA_RESULTS.md)を参照してください。

公開アプリの初回取得には通信が必要です。手元の単一HTMLを実行可能なブラウザで開いた後は、画像読み込みに追加通信を必要としない構成です。OSのファイルプレビューではJavaScriptを実行できない場合があります。

## 対応環境と未確認事項

Chrome／Edgeを主対象としています。Windows Chromiumの自動試験とローカルの診断試験を[QA_RESULTS.md](docs/QA_RESULTS.md)へ分けて記録します。**画面幅を変えたPlaywright試験は、Android／iPhoneの実機試験ではありません。** スマートフォン実機、macOS Safari、Firefox、OS間での教材受け渡し、大容量ストレス試験は未確認です。

## 開発・ビルド

生成HTMLは編集せず、`src/`と設定・ビルドスクリプトを変更します。

```powershell
pwsh -NoProfile -File ./scripts/check-powershell-syntax.ps1
pwsh -NoProfile -File ./scripts/check-repository.ps1
pwsh -NoProfile -File ./scripts/test-reveal-build.ps1
```

Windows PowerShell 5.1では`powershell.exe -NoProfile -ExecutionPolicy Bypass -File`で実行できます。テンプレートから引き継いだビルドは`tar.exe`を使用します。生成済みHTMLの利用者にはNode・npm・PowerShellの導入は不要です。

開発用テストはNode 22以上と、lockに固定したPlaywrightを使用します。

```text
npm ci
npm run test:unit
npx playwright install chromium
npm run test:e2e -- --project=chromium
```

`APP_VARIANT=self-extract`で自己展開版を試験します。CIは通常版・自己展開版を直接開き、テストレポート、通信観測、実UIの画面、実行環境を成果物へ保存します。開発依存のインストール通信は、アプリ実行時の通信とは別です。

生成物は`dist/index.html`、`dist/index.self-extract.html`、`reveal-sheet.html`です。通常版とルートコピーのバイト一致、自己展開版の復元一致を検査します。faviconとヘッダーアイコンは`assets/favicon.svg`から同じ画像を埋め込みます。実行時の依存ライブラリはありません。
