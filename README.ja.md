# Reveal Sheet / めくる暗記シート

[English](README.md)

答えが書かれた図・写真・ノートに四角い覆いを置き、めくって確認する教材を作るツールです。**現在のv0.6.0開発版では、画像と学習画面を一つにまとめた学習専用HTMLを保存でき、そのHTMLを本体でコードとして実行せず、埋め込まれたReveal Sheetデータだけを検証して再編集できます。** 自由／一問ずつ学習、端末内保存、画像入り編集データ保存も引き続き利用できます。正式版v1.0.0の完成を意味しません。

## 現在できること

JPEG・静止PNG・静止WebPを複数選択し、向きを固定したPNGへ縮小せず変換して、選択順に表示します。PCのドロップと画像ファイルの貼り付けにも対応し、失敗した画像は理由付きで分離します。

画像上に不透明な四角い覆いをドラッグまたは二点指定で作成できます。覆いはボタンや矢印キーでも移動・サイズ調整でき、複製・削除・Undo／Redoに対応します。ページ名変更、前後移動、削除も行えます。

編集パネルで複数の答え用覆いを選び、**まとめてめくる**一問にできます。グループは解除できます。補助の覆いへ変更すると、その覆いは問題数に含まれず、学習中は答えを表示しても閉じたままです。別問題や補助の覆いが重なる場合は編集画面で警告します。

覆いが一つあれば「自由にめくる」で学習できます。確認済み件数は、その学習回で一度でも開いたユニーク問題数であり、正答率・習得率ではありません。グループ化した問題はメンバーを同時に開閉します。

**一問ずつ**ではページ順・問題順に進み、答えを見るまでは自己評価できません。答えを見た後に「思い出せた／もう一度」を選ぶか、「飛ばす」で次へ進めます。結果は問題単位で集計し、「もう一度だけ確認」と「未確認を確認」は元の学習回とは別の対象集合で始めます。「習得済み」などの学習効果は表示しません。

学習中の「この問題を直す」から対象の覆いを修正し、**学習に戻る**と同じ問題・表示倍率・中心位置へ戻れます。変更した問題だけを未回答へ戻し、影響のない自己評価は保持します。画面外の問題へは「この問題へ」を明示的に押したときだけ移動します。

画像・ページ・問題・覆いを含む`.reveal.json`を保存し、「教材を開く」から元画像を選び直さず再読込できます。保存データには学習結果、Undo履歴、表示位置、元ファイル名を含めません。


**教材HTML（`.reveal.html`）**は、一問以上ある教材を画像・覆い・学習画面ごと一つのHTMLへまとめる持ち出し用ファイルです。直接ブラウザで開くと、追加通信なしで「自由にめくる」「一問ずつ」、自己評価、結果、再確認、日英切替、キーボード操作を利用できます。作者の学習結果・Undo履歴・表示位置・元ファイル名は含めません。教材HTML内から編集データ（`.reveal.json`）を保存するときも、学習結果は入りません。

本体の**教材を開く**では、`.reveal.json`に加えてReveal Sheet形式の`.reveal.html`も選べます。受け取ったHTMLはDOMとして構築したりscriptを実行したりせず、固定のJSONデータタグだけを文字列として取り出し、構造・参照・PNGを検証した後に本体UIで再構築します。外側にscript／iframe／外部画像／CSS URL等があっても採用しません。

**この端末に作業を残す**は初期OFFです。ONにした場合だけ、正規化済み画像と教材内容をブラウザのIndexedDBへ保存し、変更後約1秒でまとめて確定します。別タブから同じ保存世代が更新された場合は黙って上書きせず、自動保存を止めて「編集データを保存する／最新を読み直す」を提示します。容量不足や保存拒否でも現在画面の教材と手動保存は残ります。

**この端末に学習の続きだけを残す**も別の初期OFF設定です。画像は保存せず、問題の進み具合と自己評価だけを小さい記録として保存します。教材ID・revision・教材内容のSHA-256が一致する記録だけを再開候補にし、再開時は現在の答えを閉じます。Web Cryptoが使えない場合は学習記録の永続化だけを無効にし、通常の学習は利用できます。教材の作業保存と学習記録は別々に削除できます。

## 使い方

1. `reveal-sheet.html`または`dist/index.html`を開き、**画像を追加**します。
2. **隠す**でドラッグするか、**二点で囲む**で答えの範囲に覆いを作ります。
3. 必要なら覆い一覧から複数を選び、**まとめてめくる**を実行します。ヒント等は**学習中は隠したまま**へ変更できます。
4. **学習**で「自由にめくる」または「一問ずつ」を選びます。一問ずつでは答えを見た後に自己評価し、必要なら結果から再確認します。
5. 学習中に直したい問題は**この問題を直す**で編集し、**学習に戻る**で続けます。
6. 必要なら**この端末に作業を残す**または**この端末に学習の続きだけを残す**を個別にONにします。どちらも初期OFFです。
7. **保存**では、画像入り編集データ（`.reveal.json`）または一問以上ある場合の学習専用HTML（`.reveal.html`）を保存できます。教材HTMLは保存前に独立した学習Sessionでプレビューできます。
8. **教材を開く**では`.reveal.json`またはReveal Sheet形式の`.reveal.html`を選び、元画像を選び直さず再編集できます。

端末内保存を使わない場合でも手動の編集データ保存は常に利用できます。共有端末では端末内保存をOFFのまま使うことを推奨します。

## 対応形式と上限

| 対象 | 上限 |
|---|---|
| 入力画像1枚 | 20 MiB |
| 画像寸法 | 各辺8192 px、総画素16,000,000以下 |
| 向き固定後のPNG | 1枚32 MiB |
| 教材内の画像 | 合計64 MiB |
| ページ | 30 |
| 覆い | 全体1,000、1ページ200 |
| 問題 | 全体1,000、1問の覆い50以下 |
| 編集JSON | 96 MiB |
| 教材HTML | 100 MiB（埋め込みJSON部分は96 MiB以下） |

これらは入力拒否の安全上限であり、全端末で上限いっぱいまで処理できるという実測値ではありません。GIF、APNG、アニメーションWebP、SVG、HEIC／HEIF、AVIF、PDFは非対応です。URLやHTMLを貼り付けても外部画像を取得しません。

## プライバシー

画像と編集データはブラウザ内で処理します。元ファイル名は一時的な失敗表示だけに使い、教材データには引き継ぎません。元画像は向きを固定したPNGへ正規化し、そのPNGを編集データへ含めます。EXIFは意図してコピーしませんが、画素に写った情報は消えません。

**覆いは学習用です。元の答えや画像は編集データに含まれます。個人情報や機密情報を消す機能ではありません。**

CDN、外部フォント、計測・広告、外部APIは使用しません。CSPは`connect-src 'none'`とし、ランタイム第三者依存はありません。教材HTMLも画像・必要コード・CSS・SVGを内包し、直接開いた後の追加通信を必要としません。受信した教材HTMLの外側HTMLは実行・挿入せず、固定JSONタグだけを検証します。端末内保存はIndexedDBを利用する任意機能で、教材の作業保存と学習記録は別々に初期OFFです。ブラウザのデータ削除や保存領域の制限により失われる可能性があるため、必要な教材は`.reveal.json`でも手動保存してください。

## 対応環境と未確認事項

Chrome／Edgeを主対象としています。Windows Chromiumの自動試験とローカル診断を[QA_RESULTS.md](docs/QA_RESULTS.md)へ記録します。Playwrightの狭幅表示は実機試験ではありません。スマートフォン実機、macOS Safari、Firefox、OS間のファイル受け渡し、大容量ストレス試験は未確認です。

## 単一HTML / オフライン

アプリ生成物は`dist/index.html`、`dist/index.self-extract.html`、`reveal-sheet.html`です。利用者が保存する教材HTMLは`教材名.reveal.html`で、画像・学習画面を一つのHTMLに内包します。単一HTMLを実行可能なブラウザで開いた後、画像入力・編集・学習・編集JSON／教材HTMLの保存、Reveal Sheet教材HTMLの安全な再読込に追加通信は不要です。OSのファイルプレビューではJavaScriptを実行できない場合があります。
