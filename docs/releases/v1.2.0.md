# Reveal Sheet v1.2.0 / めくる暗記シート v1.2.0

## 主な変更

- 新しく追加する画像は端末内でWebP（品質0.86）への軽量化を試し、PNGより10%以上小さい場合にWebPを採用。OFFではPNGを使用します。
- WebPを含む保存データに形式2を追加。従来のPNG形式1は読み込めます。古いアプリでは形式2を開けません。
- スマートフォンでの画像編集、覆いの移動・微調整、ピンチ拡大と初期画面を改善。
- 出力した教材HTMLの学習UI、ヘッダー、ページ切替、問題表示を改善。
- PC向けにカメラのプレビュー・撮影を追加し、スマホの撮影方式は維持。
- 大きな画像の保存処理を見直し、エラー時の診断表示を追加。日本語・英語の説明も調整。

## Changes

- Optional WebP compression for newly added images (quality 0.86; used if at least 10% smaller than PNG). Lossy WebP can affect fine text and lines.
- Schema v2 for WebP-containing sheets; older PNG-only schema-v1 sheets remain readable. Older Reveal Sheet versions cannot open v2.
- Touch-friendly phone editing, pan/pinch zoom, refined cover adjustments and initial mobile layout.
- Refreshed standalone lesson HTML, page navigation, study controls and header spacing.
- Live camera preview and local JPEG capture on desktop; native camera input remains on mobile.
- Improved handling of large-image exports, error diagnostics and Japanese/English UI copy.

## Downloads

- `htmlapps-reveal-sheet-v1.2.0.html` — readable single HTML app
- `htmlapps-reveal-sheet-v1.2.0.self-extract.html` — self-extracting single HTML
- `htmlapps-reveal-sheet-v1.2.0.zip` — both HTML files, manifests, documentation and license
- `SHA256SUMS.txt` — checksums of the three downloads

Selected images and lesson data are processed in the browser without upload. Camera access requires a supported device, browser and permission. Automated browser tests do not cover every physical device.
