# Reveal Sheet v1.2.1 / めくる暗記シート v1.2.1

## 修正内容

- 「新しく作る」または最後のページ削除で空になった状態を端末内保存へ反映し、再読み込みで古い教材が復元候補に残らないようにしました。保存の世代管理は維持し、別タブからの古いデータの書き戻しを防ぎます。
- 書き出した教材HTMLで、ページの答えを一括表示したときの確認済み件数を、学習記録保存がONの場合に保存するよう修正しました。
- 書き出した教材HTMLの編集用JSON保存を本体と共通のダウンロード処理に変更し、URLの早すぎる破棄を避けました。保存失敗時は画面内に案内を表示します。
- 書き出した教材HTMLで確認ダイアログをEscキーで閉じた場合も、待機中の確認処理をキャンセルとして終了するようにしました。
- READMEの日英のダウンロード先とリリース情報を現状に合わせました。
- 新しいバージョンのマージ後にチェック・タグ・GitHub Releaseを作成できるよう、リリース処理を共通化しました。

## Changes

- Persist an internal empty draft state after starting a new sheet or deleting the last page. Keep its generation so stale tabs cannot resurrect an old draft; do not offer the empty state for restoration.
- Persist free-study confirmation progress after revealing all answers on a page in exported lesson HTML when local study persistence is enabled.
- Use the shared, delayed-revocation download path for editable JSON saves in exported lessons, with a localized failure message.
- Resolve confirmation dialogs as canceled when they close via Escape.
- Correct English and Japanese README download instructions and release information.
- Generalize the validated post-merge GitHub release workflow for subsequent versions.
