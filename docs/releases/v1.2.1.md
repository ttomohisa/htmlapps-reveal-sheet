# Reveal Sheet v1.2.1 / めくる暗記シート v1.2.1

## 修正内容

- 編集用ファイルと学習用HTMLの保存ボタンを同じ高さにそろえ、プレビューは2つの保存形式の下へ移しました。 デスクトップとスマートフォンの学習UIは実際の画面キャプチャでも確認しました。
- 自由にめくる学習画面の重複した見出しをなくし、進捗・一括操作・問題ごとの答えの表示切替を整理しました。スマートフォンの狭い画面と日英表示も調整しました。
- 保存画面を編集用ファイルと学習用HTMLの2つの選択肢に整理しました。容量と補助の覆いの詳細は折りたたみ、エラーが起きたときだけ診断内容を表示します。ファイル名欄を自動選択せず、保存画面の見出しにフォーカスを移します。
- 自動保存の説明文を簡潔にし、画像容量の下の不要な案内と区切り線を削除しました。
- ヘッダー・本文・フッターの左端を統一しました。画像を追加すると説明と完全ローカル処理の表示を隠します。
- 画像の追加・撮影・保存済み教材を開く操作と、画像の設定を分けて表示します。この端末への作業保存は初期状態で折りたたみ、別タブとの保存競合時は自動で開きます。
- 作成画面のヒーロー見出しをなくし、図やノートから暗記シートを作る流れを短い説明文にまとめました。英語版も同じ内容に調整しました。
- スマートフォンでは「完全ローカル処理」の表示を隠し、作成・学習画面のカードや枠線を控えめにしました。書き出した教材HTMLの影も減らしました。
- 「新しく作る」または最後のページ削除で空になった状態を端末内保存へ反映し、再読み込みで古い教材が復元候補に残らないようにしました。保存の世代管理は維持し、別タブからの古いデータの書き戻しを防ぎます。
- 書き出した教材HTMLで、ページの答えを一括表示したときの確認済み件数を、学習記録保存がONの場合に保存するよう修正しました。
- 書き出した教材HTMLで、学習記録の保存をONにして確認してもチェックが反映されない問題を修正しました。
- 書き出した教材HTMLの編集用JSON保存を本体と共通のダウンロード処理に変更し、URLの早すぎる破棄を避けました。保存失敗時は画面内に案内を表示します。
- 書き出した教材HTMLで確認ダイアログをEscキーで閉じた場合も、待機中の確認処理をキャンセルとして終了するようにしました。
- READMEの日英のダウンロード先とリリース情報を現状に合わせました。
- 新しいバージョンのマージ後にチェック・タグ・GitHub Releaseを作成できるよう、リリース処理を共通化しました。

## Changes

- Align the editable and study HTML save buttons vertically, with the lesson preview below the two formats. Capture the free-study controls on mobile for release QA.
- Simplify free-study controls: remove the duplicated heading, group progress and bulk actions, and present numbered answer toggles with clear reveal/hide states on desktop and mobile.
- Redesign the save screen around two clearly explained choices: an editable file and a study HTML. Collapse technical capacity details and only show diagnostics after an error; focus the save heading instead of the filename field.
- Simplify the optional on-device autosave explanation and remove the redundant banner and dividers below the workspace.
- Align footer content with header and main text; hide the introductory text and local-processing badge once an image is loaded.
- Separate image import, camera and saved-sheet actions from image settings. Collapse the on-device saving section by default and expand it when a cross-tab conflict occurs.
- Replace the redundant hero heading with a short Japanese/English explanation of creating study sheets from diagrams or notes.
- Hide the local-processing badge on phones and soften decorative borders, card backgrounds and shadows in the editor, study views and exported lessons.
- Persist an internal empty draft state after starting a new sheet or deleting the last page. Keep its generation so stale tabs cannot resurrect an old draft; do not offer the empty state for restoration.
- Persist free-study confirmation progress after revealing all answers on a page in exported lesson HTML when local study persistence is enabled.
- Fix the exported lesson opt-in checkbox not updating after the confirmation dialog was accepted.
- Use the shared, delayed-revocation download path for editable JSON saves in exported lessons, with a localized failure message.
- Resolve confirmation dialogs as canceled when they close via Escape.
- Correct English and Japanese README download instructions and release information.
- Generalize the validated post-merge GitHub release workflow for subsequent versions.
